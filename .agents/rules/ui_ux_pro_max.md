# UI/UX Pro Max Guidelines

When developing features for the ASKMEBAG project, you must adhere to the following design system principles:

1. **Typography**: Use standard premium pairings (e.g., Playfair Display for accents/serif headers, Inter for standard body text).
2. **Color Palette**: Utilize off-whites, beiges, deep blacks, and gold/brown accents to maintain a bespoke physical product aesthetic.
3. **Responsive Design**: Ensure ALL layouts fall back to stacked columns on mobile (`max-width: 768px`) gracefully without breaking horizontal bounds.
4. **Micro-Interactions**: Use Framer Motion for scroll reveals, fade-ins, and button hover states.
5. **Visual QA**: No generic placeholders; use properly sourced imagery and ensure pixel-perfect padding/margins matching high-end references.
